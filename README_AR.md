# Solunar Tide Core

**مكتبة خفيفة لحساب أوقات الصيد (سولونار) ووقت النشاط، بدون إنترنت** — مكتوبة بلغة Dart بالكامل، **بدون اتصال بالشبكة، بدون مفتاح API، بدون أي تبعيات خارجية** (رخصة MIT).

> النسخة العربية · الوثائق الكاملة (إنجليزية): [README.md](README.md) · ألمانية: [README_DE.md](README_DE.md)

---

## لماذا هذه المكتبة؟

يستخدم العديد من الصيادين **تقويم سولونار** (Solunar) للتنبؤ بأفضل أوقات الصيد. توفّر هذه المكتبة نفس الفكرة **كمكتبة مفتوحة المصدر تعمل دون اتصال**، لأي مطوّر يبني تطبيق صيد:

- ☀️ **الشروق والغروب** — حساب شمسي مبسّط، لأي خط عرض وطول
- 🌙 **طور القمر** — الشهر الاقتراني + تصنيف الأطوار
- 🎯 **درجة أوقات الصيد (0–100)** — أفضل النوافذ حول الشروق +1ساعة والغروب −2ساعة
- 📊 **أفضل نوافذ الصيد** — فترات متتالية عالية الدرجة خلال اليوم
- 🐟 **تقييم متعدد العوامل** — حرارة الماء، الضغط الجوي، الرياح، القمر والوقت، وغيرها
- 🗓️ **منحنى الصيد بالساعة وتوقعات الأيام القادمة**
- 🐠 **9 أنواع سمك جاهزة** — قابلة للتوسيع
- ⚡ **يعمل 100% دون اتصال** — لا تُرسل أي بيانات خارج الجهاز
- 🧩 **بدون أي تبعيات خارجية** — يعمل مع Flutter و CLI

## بدء سريع

```dart
import 'package:solunar_tide_core/solunar_tide.dart';

void main() {
  final sun = AstroUtils.sunTimes(DateTime(2026, 10, 31), 32.0, -85.0, -360);
  final moon = AstroUtils.moonPhase(DateTime(2026, 10, 31));
  if (sun == null) return;

  final score = SolunarScore.timeMoonScore(
    DateTime(2026, 10, 31, 6, 30), sun.$1, sun.$2, moon,
  );
  print('درجة وقت الصيد: $score/100');
}
```
